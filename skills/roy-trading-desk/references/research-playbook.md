# 研究手册（mode=research / mode=review 用）

## 1. 每日研判顺序

1. **时间与日历**：当前 ET、是否交易日、距开盘/收盘时长。
2. **市场状态**：两个基准 ETF（默认 VTI/QQQM）的 6 个月回报与 200 日均线位置（收盘确认）；50 日均线、3 个月回报、波动作辅助。得出当日股票仓位上限档位。
3. **回撤水位**：净值 vs 高水位，落在哪一档回撤门。
4. **宏观与新闻**（一手优先）：Fed/FOMC、BLS 就业与通胀、SEC 公告、重大财报、地缘政治；每条区分【事实】【市场反应】【推断】，附链接。
5. **持仓逐个复核**：论点是否仍成立、失效条件是否接近、财报日期；**不在异动榜也要复核**。
6. **候选初筛**（如做）：见下节。

## 2. 候选股漏斗（全过才有资格进 decide）

量化硬门（闸门会再验一遍）：价格 ≥$5、市值 ≥$100 亿、日均量 ≥100 万股、站上 50/200 日线、3/6 个月回报为正、20 日相对基准更强、距财报 >2 个交易日。

之上的研究软门（LLM 职责）：
- 入场形态二选一：放量突破 20 日高；或回踩 20/50 日均线企稳且动量重拾。
- 论点必须落纸：论点 / 反论点 / 失效条件三件齐才算候选，缺一即弃。
- 行业去重视角：优先能降低组合与你的长期核心资产（如养老金账户）重复度的行业，是优先级不是硬凑。
- 一票否决：单条新闻不能创造买入；盘中暴涨不是理由；"接近挑战目标"永远不是理由。

## 3. 新闻纪律

- 新闻是**风险覆盖层**：可以推迟、缩量或否决一张卡；不能作为唯一入场依据。
- 来源分层：一手（监管/发行商/公司 IR）> 主流财经媒体 > 聚合/社媒（仅作线索，必须回溯一手核实）。
- 每条引用给出可点击链接与时间戳；转述与原文区分。

## 4. 复盘清单（mode=review）

- 当日：卡 vs 成交核对（执行率、偏离及原因）、组合权重 vs 目标、回撤水位变化、明日触发条件。
- 每周：跑 `behavior_review.py`，看四项偏差指标趋势；胜负单持有期对比；决策卡质量抽查（失效条件是否真的可判定）。
- 每月：策略参数体检——市场状态档位切换次数、回撤门触发记录、换手与频次利用率；形成至多一个 evolve 提案。

## 5. 行为偏差速查（画像脚本检测的四项）

| 偏差 | 信号 | if-then 对策模板 |
|------|------|------------------|
| 过度交易 | 笔数/换手长期贴上限 | if 本周笔数已达 X then 只出观察卡 |
| 处置效应 | 盈利单持有期 << 亏损单 | if 想卖盈利单 then 先检查失效条件是否真触发 |
| 追涨 | 买入前 5 日涨幅经常 >10% | if 5日涨幅>10% then 要求回踩企稳形态才出卡 |
| 卡偏离 | 实际执行常偏离决策卡 | if 连续 N 次偏离 then 复盘卡的可执行性而不是加卡 |
